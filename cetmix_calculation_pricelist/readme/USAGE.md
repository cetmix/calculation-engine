1. Configure Pricelists

- Navigate to *Sales app -> Products -> Pricelists*.

- On the Pricelists page, either select an existing pricelist to edit or click *New* to create a new pricelist.

- On the pricelist form, under the *Price Rules* tab, click *Add a line* to add an advanced price rule. This will open the *Create Pricelist Rules* pop-up form, where the advanced rule is configured.

- Choose the *Formula* Price Computation option.

- A *Calculation* selection field will appear; select the desired price calculation.

- In the *Based on* dropdown list, select the desired price base.

- The rule will now be based on the that price base.
